Commit message generation through a terminal agent

2026-10-11 and 2026-10-18. 60 real commits of openai/codex and JetBrains/intellij-community, diff from 0.4 KB to 102.0 KB, 1 runs per commit and agent. Cheap models only. Claude Code 2.1.291, codex-cli 0.154.0, codex-acp 2.2.2, claude-agent-acp 0.89.1, Junie 26.10.5, pi 0.84.2, macOS.

Verdict

Use the CLI mode, not ACPclaude -p, codex exec, and pi -p give the message in 2–3 seconds for less than 2 cents. The IDE collects the diff and gives it to the agent; the agent only writes text.
Claude Code and Codex are readyAll runs succeeded and the output was clean text. Haiku 4.5 is the fastest; Haiku 5.5 writes the best explanations; Luna writes short and exact messages.
pi is ready tooWith ten switches pi -p sends only our system prompt, the working directory, and the prompt: 1.7 s per message with Luna, 2.2 s with Haiku 4.5. pi has no model of its own: it calls the provider of the user with the user's key.
Junie is not suitable todayIts CLI returns a task report instead of the message and makes several model calls. Its ACP mode needs the IDE for authorization.
Do not trust issue ids from the model21 of the 72 ids that the models wrote were wrong. The IDE takes the id from the branch name only.
