## Verdict

- ✅ **Use the CLI mode.** `claude -p` and `codex exec` return the message in 2–3 s. The IDE collects the diff; the agent only writes text.
- ✅ **Claude Code and Codex are ready.** Every run returned clean text: no quotes, no fences, no preamble.
- 🟡 **ACP works, but costs more.** ACP has no system prompt and no switches to cut the context, so every call carries the full agent setup.
- ✅ **OpenCode is the exception.** The client starts `opencode acp` with our agent in `OPENCODE_CONFIG_CONTENT`: our system prompt, no tools, no title call. A message then takes 2.9 s with Luna, 1.0 s of it the start of the process.
- ❌ **Junie is not suitable today.** Its CLI returns a task report instead of the message. Its ACP mode needs a JetBrains IDE for the login.
- ⚠️ **Do not trust issue ids from the model.** 25 of the 90 ids that the models wrote were wrong: an id of an unrelated commit, or an invented one. Keep only the ids from the branch name.

## Agents

### ✅ Claude Code: Haiku 4.5

- The cheapest per message.
- Needs four switches against user settings, see the README.

### ✅ Claude Code: Haiku 5.5

- Explains why a change was made more often than the other models.
- Claude Code 2.1.291 does not know this model: the reported cost is not reliable.

### ✅ Codex: GPT-5.6 Luna

- Short and exact messages, rarely a body.
- The CLI reports tokens, not a price.

### ✅ OpenCode ACP lean: GPT-5.6 Luna

- The only ACP agent that takes a config from its client: our system prompt and no tools in `OPENCODE_CONFIG_CONTENT`.
- 1.0 s of the time is the start of the process: spawn, `initialize`, and `session/new`.
- 0.7× the input tokens of `codex exec`.

### ✅ OpenCode ACP lean: Haiku 4.5

- Needs the effort `default`: without it ACP takes the first variant of the model, and Haiku 4.5 thinks with a 16k budget.
- 1.5× the time of `claude -p`, most of it the start of the process.

### ✅ OpenCode ACP lean: Haiku 5.5

- OpenCode knows the price of Haiku 5.5: $0.0010 per message, against $0.0074 for Haiku 4.5.

### 🟡 Codex ACP: GPT-5.6 Luna

- ACP has no system prompt and no switches to cut the context: every call carries the full agent setup.
- 3.1× the input tokens of `codex exec`.

### 🟡 Claude ACP: Haiku

- ACP takes none of the `claude -p` switches: the full Claude Code prompt, tools, hooks, and user settings come with every call.
- 4.4× the input tokens and 2.4× the time of `claude -p`.
- Without a model switch the session uses the default model of the user, Opus in this test: $0.15 for one word.

### 🟡 OpenCode ACP: GPT-5.6 Luna

- The default `build` agent: the OpenCode system prompt and 9 tools, 2.4× the input tokens of our agent.
- One more call per message: the session title. It sends the whole prompt to gpt-5.4-nano once more, and the ACP usage does not count it.
- Without a model switch the session uses `opencode/big-pickle`, a free model of OpenCode Zen: the diff goes to opencode.ai.

### 🟡 OpenCode ACP: Haiku 4.5

- ACP takes the first effort variant of the model: Haiku 4.5 thinks with a 16k budget, 3.4× the time of our agent.
- The title call sends the whole prompt to Haiku 5.5 once more.
- One answer asked the user for the branch name instead of writing the message (intellij-community-15): the default agent is made for a conversation.

### ❌ Junie: junie-lite

- Returns a Markdown task report, not the message. 2 of 60 reports held the message in a code block.
- Runs a full agent loop: 8 model calls per message, 3.4× the time of `claude -p`.
- The test account could use only junie-lite. Other models: authorization failed.

### ❌ Junie ACP: GPT-5.6 Luna (JetBrains AI)

- Outside an IDE every prompt ends at once with `cancelled`: the JetBrains AI authorization fails.
- A JetBrains IDE gives Junie its credentials when it starts the agent. A test needs a running IDE.
